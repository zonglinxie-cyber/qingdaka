# RESEARCH · 轻活动习惯与作息的依据

整理与访问核对日期：**2026-11-05**。

本文记录官方健康机构、专业学会及平台文档对产品决策的支持范围。它是来源与设计之间的说明，不是系统综述、个体运动处方、临床验证报告或专业审核证明；不记录任何使用者的个人资料。

## 1. 如何区分证据与设计

- **来源结论**：原文提供的一般健康建议、临床指导边界或平台能力说明，下面以摘要表达，不当作逐字引文。
- **产品推导**：项目据此选择的交互、措辞、数据与计时规则。采用一般原则，不等于本项目的具体做法已经被来源机构验证。
- **待验证假设**：短回合是否更容易开始、示意是否看得懂、记录是否有帮助，需要专业校对与实际使用验证；不能只凭引用推导疗效。

本次已读取以下链接的相关正文。健康网页与技术文档可能更新，日期是本项目核对日期，不代表所有页面都在当日发布，也不代表本项目获得机构背书。

## 2. 活动：少量开始，但不把小回合当作完整运动处方

### WHO · Physical activity

来源：<https://www.who.int/news-room/fact-sheets/detail/physical-activity>

- **来源结论**：任何量的身体活动都优于完全不活动；应减少久坐。长期公共健康建议涉及频率、强度与时长，成人每周至少 150 分钟中等强度活动是相关参考之一。
- **产品推导**：允许从一个很小的行动开始，不用“尚未达到长期建议”制造欠账；只展示已记录的行为。
- **不能推出**：1／3／5 分钟课程足以达到长期建议，或坐姿、小幅动作都属于中等强度运动。“少量也有意义”不凌驾于急症、发作和不适时停止的要求。

### NIDDK · Staying Active at Any Size

来源：<https://www.niddk.nih.gov/health-information/weight-management/staying-active-at-any-size>

- **来源结论**：长期不活动后应慢慢开始、观察感受；短时间活动、步行和坐姿活动可以是开始方式。容易气短、活动或平衡困难、慢性病、骨关节问题及对安全有疑虑时，开始前应咨询专业人员。不舒服时停止；胸部疼痛／压迫、严重气短、头晕或恶心等警示需要及时求助。
- **产品推导**：先看动作、主动选择坐／站、短回合可随时停止；安全提示先于开始按钮，不以身体指标决定是否“值得”开始。
- **不能推出**：所有人都适合坐姿、发作时换坐姿即可继续，或原文认可本项目的具体动作组合和秒数。原文谈逐步增加活动，不等于软件应根据连续打卡自动加量。

### NHS · Sitting exercises

来源：<https://www.nhs.uk/live-well/exercise/sitting-exercises/>

- **来源结论**：选择稳固无轮的椅子，双脚能平放，衣物舒适；不确定适合性时咨询专业人员。页面包含开胸、交替抬膝、温和转头等坐姿动作，并给出自身的次数、保持时间和逐步增加建议。
- **产品推导**：借鉴稳定坐姿、肩向后下、控制抬膝及舒适范围内转头等要点；用原创 SVG 和短文字解释，小幅、慢速、不追次数。开胸和转头仅在舒适时短暂停留，不要求撑满计时。
- **不能推出**：项目复制了整套 NHS 课程或原始剂量。项目修改过动作幅度提示、选取范围与节奏；六个动作及各阶段的全部图文仍需专业校对。自制图不等于专业视频，也不能精确表达适用于每个人的关节角度。

### 项目自定的回合安排

| 选择 | 含准备／休息／收尾的总时长 | 计划 `move` 上限 |
| --- | --- | --- |
| 1 分钟 | 60 秒 | 20 秒 |
| 3 分钟 | 180 秒 | 80 秒 |

以上是**降低操作门槛的产品设计**，不是任何来源给出的最低有效剂量、康复方案或必须完成量。准备、休息与收尾不计入 `activeSeconds`；暂停、跳过和提前结束按实际运行记录，不用预定时长冒充完成。计时并未测量身体动作，不能证明能量消耗、训练强度或运动疗效。

## 3. 发作与症状：休息和求助优先

### NHS · Gout

来源：<https://www.nhs.uk/conditions/gout/>

- **来源结论**：发作时休息并抬高患肢，不给患处施压；首次出现症状或既有处理无效时应求医。突然关节疼痛和肿胀，伴疼痛加重、发热／寒战或恶心／不能进食等，可能提示关节感染，需要紧急医疗帮助。
- **产品推导**：痛风发作、疑似发作或相关不适时不开始或继续常规回合；不自动换坐姿或换动作硬撑。关节警示不一概解释为普通发作或练后反应。
- **不能推出**：网页能确诊痛风、排除感染、决定何时恢复运动或给出药物建议。原文的补水提醒也不转化为本产品的统一饮水目标。

### NIAMS · Gout: Diagnosis, Treatment, and Steps to Take

来源：<https://www.niams.nih.gov/health-topics/gout/diagnosis-treatment-and-steps-to-take>

- **来源结论**：痛风诊断需要医疗评估，其他情况可以表现相似；发作时可休息患处、抬高患肢等。反复发作或痛风石等情况下，生活方式改变本身不足以替代相应医疗治疗。
- **产品推导**：提示按已有医疗建议处理并联系医生；应用只支持停止和休息记录，不承担治疗或复发预防方案。
- **不能推出**：做这些小回合、调整作息或坚持打卡能治疗痛风，或替代药物管理。是否运动和何时恢复应由实际身体状态及专业建议决定。

急症入口优先求助、无需先保存记录，是项目的风险控制设计。安全勾选不是筛查量表，未出现某一条列举症状也不是继续活动的保证。

## 4. 作息：提供习惯支持，不考核或治疗睡眠

### NHLBI · Healthy Sleep Habits

来源：<https://www.nhlbi.nih.gov/health/sleep-deprivation/healthy-sleep-habits>

- **来源结论**：先留够睡眠时间；尽量规律上床和起床，工作日与周末差异尽量不超过约 1 小时；睡前约一小时安排安静活动，避免强光与剧烈活动，保持卧室安静、凉爽、昏暗。咖啡因影响可能持续长达 8 小时，白天适当户外活动也是一般建议。
- **产品推导**：设置现实的起床锚点和开始收尾的计划时间，提供调暗灯、结束刺激内容、放下手机等入口。收尾可次日补记，不为打卡推迟睡眠。
- **不能推出**：固定时间保证睡着、越早起越好，或简短收尾等于完整睡眠干预。咖啡因提醒是观察与调整的线索，不是人人适用的固定安全线。

### NHS · Insomnia

来源：<https://www.nhs.uk/conditions/insomnia/>

- **来源结论**：睡眠需求有差异，成人通常约需 7–9 小时；困了再上床、规律起床、睡前放松是一般建议。调整习惯无效、问题持续数月或影响日常生活时应求医；医生可能提供认知行为治疗等支持，困倦时不应驾驶。
- **产品推导**：不因起床锚点而压缩睡眠；只记录实际起床和是否做了收尾，保留持续困扰时求助的提示，不以“自律不足”解释睡不好。
- **不能推出**：起床时间或收尾标记能推算入睡时间、睡眠时长、质量或诊断失眠。应用不自行开展睡眠限制治疗，也不制定助眠用药方案。

### AASM · New guideline supports behavioral, psychological treatments for insomnia

来源：<https://aasm.org/new-guideline-supports-behavioral-psychological-treatments-for-insomnia/>

- **来源结论**：这篇专业学会的指南发布说明介绍成人慢性失眠的行为与心理治疗，强推荐多组分 CBT-I；并指出**睡眠卫生不应作为成人慢性失眠的单一治疗**。
- **产品推导**：将一般作息提示与失眠治疗明确分开，长期或影响生活的问题转向专业帮助。
- **不能推出**：本应用提供 CBT-I、达到指南推荐治疗的效果，或仅靠作息清单就能治疗慢性失眠。本次读取的是指南发布说明，不声称完成了指南全文及全部原始研究的系统审查。

### NHS · Sleep apnoea

来源：<https://www.nhs.uk/conditions/sleep-apnoea/>

- **来源结论**：睡眠中呼吸停停续续、喘气／憋醒、大声打鼾等是主要症状，日间也可能疲倦；疑似情况需要医疗评估，可能需要睡眠检查与治疗。生活方式支持不能自动替代诊断和适当治疗。
- **产品推导**：在作息说明中保留憋醒、被观察到呼吸停止及明显日间困倦等就医提醒；不等待某个行为目标达成才建议就医，困倦影响警觉时避免驾驶。
- **不能推出**：没有嗜睡就排除睡眠呼吸问题，或应用能通过自填记录诊断／治疗睡眠呼吸暂停。文中的英国服务与驾驶规定不直接转写成其他地区的法律要求。

来源对睡前活动和咖啡因的具体措辞并不完全相同：NHS 给出一般时间建议，NHLBI 强调睡前安静、避免剧烈活动及咖啡因影响。项目采用保守、可调整的生活提示，不把其中一个时间点包装成适合所有人的临床阈值。

## 5. 行为设计：小目标、行动计划和对中断的准备

### NICE PH49 · Behaviour change: individual approaches

来源：<https://www.nice.org.uk/guidance/ph49/chapter/1-Recommendations>

- **来源结论**：建议 7 涉及目标与行动计划、反馈和自我记录；建议 8 强调个体需要、能力和环境；建议 10 涉及应对中断的计划与小而可管理的日常改变。建议 16 要求明确目标并评价干预，不能仅凭采用某个技术就推断有效。
- **产品推导**：将活动接在已有日常事件之后；首页先选一个重点；只记录实际做过的事情与感受；中断后从可行的小目标重新开始，不设补课欠账或自动升级。
- **不能推出**：NICE 验证了本项目的界面、默认时长、连续使用效果或健康结局。产品不等同于由受训人员实施的完整行为干预，也未提供指南所述的长期跟进服务。

待验证的问题包括：是否能看懂并自主开始，能否轻松退出，反馈是否带来负担，以及能否正确理解记录。评价应采用自愿、必要、去标识的可用性反馈，不为研究名义增加个人健康资料收集或后台追踪。

## 6. 平台：离线不等于可靠的后台闹钟

### WebKit · Web Push for Web Apps on iOS and iPadOS

来源：<https://webkit.org/blog/13878/web-push-for-web-apps-on-ios-and-ipados/>

- **来源结论**：iOS／iPadOS 16.4 为添加到主屏幕的 Web App 引入 Web Push 支持；请求通知许可需要直接用户交互，实际通知受系统权限与专注模式等设置影响。能力由 Push API、Notifications API 和 Service Worker 配合实现。
- **产品推导**：不能因为采用 PWA 就宣称具备系统闹钟能力。本项目没有实现推送服务或订阅，起床与收尾提醒交由用户自行设置系统工具。
- **不能推出**：所有 iPhone 网页完全不支持推送，或相反，纯本地网页可以不经授权和相关基础设施在后台准点提醒。

### MDN · Offline and background operation

来源：<https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Offline_and_background_operation>

- **来源结论**：Service Worker 可缓存资源支持离线访问，但不是持续运行的进程；浏览器可以停止它。后台同步由浏览器调度，周期同步请求的间隔不是准点执行承诺；Web Push 涉及服务器、推送服务和用户许可。
- **产品推导**：离线功能只承诺在完整缓存可用时访问对应资源；前台回合切后台暂停，checkpoint 恢复为暂停，不补算漏掉的时间。网页里的计划时间不冒充已创建的系统提醒。
- **不能推出**：安装到主屏、缓存就绪或申请屏幕常亮能保证后台计时、永久数据保存或锁屏准点通知。具体 iPhone 行为仍需真机验证。

## 7. 待取得的证据

1. **专业内容校对**：文字与 SVG、停止／求助提示、作息边界是否恰当；尚不能标记为审核通过。
2. **iPhone 真机验证**：Safari 与主屏模式的中断、恢复、离线、备份、音频及更新；桌面浏览器和单测结果不能代替。
3. **实际使用验证**：开始与停止是否容易、记录是否被正确理解、是否带来额外压力；不直接推导健康疗效或长期习惯形成。
