# 轻打卡 · 单动作展示样例 01

这是用于确认视觉与跟练交互方向的独立样例，**不接入正式课程、不保存锻炼数据、未发布到线上**。先看效果，再决定是否推广到其他动作。

## 看什么

- **一个完整人物**：原创有体积的 2D 人物与椅子，不是火柴人、真人视频或预渲染 3D。
- **学习与预览分开**：学习页不倒计时，可循环播放或查看“坐稳 / 轻抬 / 放回”；回合预览为 5 秒准备、20 秒演示、10 秒休息，仅用于界面体验，不是正式课程剂量。
- **小幅动作过程**：抬起、放回、落稳再换侧；上身和椅子保持固定。动画幅度与速度不是训练目标。
- **可随时停**：暂停同时停止计时、动画与语音，离页 / 后台 / 长时间停顿后需手动继续，不补后台时间；休息时移除人物展示。
- **可选口令**：默认关闭，只选浏览器报告为本机的中文声音；无语音、播放失败时保留文字，不调用第三方语音服务。
- **减少动态**：遵循系统偏好，默认显示静态分步；连续动画须主动开启。

**人物和动作尚未经过专业校对，请先只看，不跟做。**痛风发作或疑似发作时不开始或继续活动，不自动换做坐姿。完整注意事项在页面底部可展开。

## 打开

桌面浏览器可直接打开本目录的 `index.html`，不需要构建、登录或安装依赖。页面只使用同目录的 HTML、CSS、JS，无远程图片、字体或视频。

在项目根目录启动局域网预览：

```sh
python3 serve.py 8899 --lan --directory docs/prototypes/gentle-coach
```

手机与电脑连接同一个可信 Wi-Fi，打开命令输出的“手机同 Wi-Fi 打开”地址。桌面使用 `http://127.0.0.1:8899/index.html`。停止时按 `Ctrl+C`。

`--lan` 会把这个样例目录开放给当前网络中的设备；只在可信网络中使用。没有登录保护，不应把服务转发到公网。此服务根目录只包含样例，不开放项目其他文件。

样例不注册 Service Worker。已打开页面断网可继续交互，**不代表支持手机离线冷启动、主屏安装或正式应用的完整离线流程**。

## 文件与验证

- `index.html`：独立页面、原创 SVG 人物与说明。
- `prototype.css`：米白 / 深绿视觉、手机布局、短屏处理与暂停按钮定位。
- `prototype.js`：只在内存中的预览状态、动画、语音与暂停控制。
- `../../../scripts/test-coach-prototype.mjs`：Playwright 验证。
- `../../../scripts/capture-coach-prototype.mjs`：可重复生成上述截图和动图。

在项目根目录执行：

```sh
node scripts/test-coach-prototype.mjs
node scripts/capture-coach-prototype.mjs
node scripts/build-dist.mjs --check
```

测试与截图使用项目现有 Playwright 和独立临时 Chrome context，不连接用户浏览器；测试服务结束后关闭。动图合成额外使用本机已有的 Python Pillow，不是样例运行依赖。

2026-11-06 验证结果：

- 25 / 25 项通过：学习 / 暂停 / 分步 / 回合自然结束、语音取消与失败降级、减少动态、后台与长间隔暂停、390×844 和 320×560 布局、已打开页面离线运行、`file://` 直接打开、存储 / 外部请求 / SW 审计等。
- Chrome 157 桌面浏览器手机尺寸；语音通过 mock 验证，离页通过确定性事件模拟。
- 实际截图检查：人物与脚部不被播放按钮遮挡；320×560 回合首屏可看到完整人物及暂停 / 结束按钮。
- 正式构建只读预检通过，版本仍为 `habits-202a71d31ae99825ed2f`；`dist` 未改动，样例未进入发布白名单。
- **未做 iPhone 真机 / WebKit 验证、真实语音听感与离线语音验证、专业动作审核。**

## 推广前的门槛

1. 先确认这套人物、尺寸与交互确实优于原展示；不要未经确认批量替换。
2. 对侧面遮挡、双手支撑与换侧过程做专业动作校对；技术测试不能证明动作适合某个人。
3. 若转向真人短视频，先解决动作准确性、素材授权与拍摄，再做播放器；不能用相似但不匹配的素材替代。
4. 在用户的 iPhone 上确认人物大小、口令、切后台、静态回退与触控。
5. 接入正式课程时保留既有安全入口、活动时间口径、暂停恢复与数据可靠性；不要复用本样例的内存状态作为正式会话系统。
