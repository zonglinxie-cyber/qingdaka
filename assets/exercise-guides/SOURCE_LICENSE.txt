chair-stand-steps.svg is an original, hand-authored vector schematic of
unweighted sit-to-stand positions. It is a static teaching aid, not a filmed
or professionally validated demonstration. No third-party media was used. It
is the demonstration for 扶椅坐站 in every routine; the dataset GIF 0291 shows
a person holding dumbbells and is kept only for 扶凳箱式深蹲 (居家哑铃).

kneeling-plank-steady.svg / kneeling-plank-tap.svg are original, hand-authored
vector schematics of the kneeling forearm plank drawn from the same side-view
language as chair-stand-steps.svg: frame 1 is the straight head-shoulder-hip-
knee line with the forearms planted and the knees on the mat, frame 2 lifts one
hand to the opposite shoulder. They replace dataset GIF 3239, whose legs are
extended on the toes and therefore did not show the kneeling version the
written cues ask for. Same caveat as above: static teaching aids drawn for this
app, not filmed or professionally validated demonstrations, and no third-party
media was used as an input or reference for them.

hip-bridge-flat.svg / hip-bridge-lift.svg are original, hand-authored vector
schematics of the glute bridge in the same side-view language: frame 1 is lying
on the mat with the knees bent and both soles flat, frame 2 lifts the hips until
a dashed rule shows shoulder-hip-knee in one line. They replace dataset GIF
3013, an anatomical muscle illustration whose still frame shows only the raised
position and gives a reduced-motion reader no setup position to copy. Same
caveat as above: static teaching aids drawn for this app, not filmed or
professionally validated demonstrations, and no third-party media was used as an
input or reference for them.

dead-bug-tabletop.svg / dead-bug-reach.svg are original, hand-authored vector
schematics of the dead bug in the same side-view language: frame 1 is lying on
the mat with the arms reaching up and the hips and knees at about 90 degrees,
frame 2 lowers the near-side hand behind the head while the opposite (far-side)
leg reaches forward and down, with a small arrow over the abdomen for the lower
back staying pressed to the mat. They replace dataset GIF 0276, whose motion did
match the written cues but which is an anatomical muscle illustration: it sits
between three project-authored schematics in the same beginner routine and reads
like a different app, and the file itself is covered by the release restriction
in section 3. Same caveat as above: static teaching aids drawn for this app, not
filmed or professionally validated demonstrations, and no third-party media was
used as an input or reference for them.

wall-pushup-start.svg / wall-pushup-bend.svg are original, hand-authored vector
schematics of the wall push-up in the same side-view language, drawn on a
portrait canvas because a standing figure does not fit the square ones used for
the floor moves: frame 1 is facing the wall with the palms on it and the arms
nearly straight, frame 2 keeps the palms and the feet exactly where they were
and only bends the elbows, with a dashed rule from head to ankle for the body
staying one straight line. They replace dataset GIF 0659, the last outside GIF
in the default bodyweight routine. Its motion did match the written cues; it is
replaced because the GIF draws the whole movement as onion-skinned ghosting,
i.e. several translucent copies of the same body inside one frame, which reads
as a smudge at phone size instead of giving a position to copy, and because the
file itself is covered by the release restriction in section 3. Same caveat as
above: static teaching aids drawn for this app, not filmed or professionally
validated demonstrations, and no third-party media was used as an input or
reference for them.

towel-row-ready.svg / towel-row-pull.svg are original, hand-authored vector
schematics of the seated towel row in the same side-view language, drawn on the
same square canvas as the floor moves because the body is seated and seen from
the side: frame 1 is sitting on the chair with the knees at about 90 degrees,
the towel passed under the forefoot and each hand taking one end in front of the
knees, frame 2 keeps the chair, hips, knees, soles and the foot end of the towel
exactly where they were and moves only the arms, with the elbows drawn back
along the sides of the body and both hands up at the waist and a small arrow in
front of the hands pointing back toward the body. They replace the 坐姿毛巾划船
text-only "no demo" screen, which was the last such screen in the default
bodyweight routine. No dataset GIF stands in for them here: 3165 shows a
standing row with the towel at hand-rail height, which is not the seated
position the written cues ask for, and that file had already been removed from
the tree (see section 3). Same caveat as above: static teaching aids drawn for
this app, not filmed or professionally validated demonstrations, and no
third-party media was used as an input or reference for them.

The bird-dog.gif / bird-dog-poster.png pair is a project-original looping
demonstration generated for this app (four-point kneel to contralateral
reach). It was not derived from a RepDB or Kaggle GIF, and no third-party
exercise GIF was used as an image input or style reference.

Status:
  PROJECT-ORIGINAL GENERATED ASSETS. wall-plank-anatomy.png is a 512 x 512 PNG
  still generated specifically for Workbuddy to match its anatomical
  illustration language, from text-only project art direction. The
  farmer-carry and bird-dog anatomy stills that were generated from it as a
  style reference have been removed from the shipped set; bird dog now uses the
  project-original looping GIF above, and 轻负重行走 uses dataset GIF 2133.

Usage:
  wall-plank-anatomy.png is the deployed static reference for wall plank. It is
  not a complete motion demonstration. Keep the written regressions, safety
  cues, and "static posture reference" labels with it.

complete or reliable chain of title for the media.

Source repository and dataset:
  https://github.com/omercotkd/exercises-gifs  (assets/<id>.gif)
  Underlying Kaggle dataset: "Fitness Exercises with Animations"
  (edoardoba) — the same source as the legacy strength GIFs in section 3.

  background to match the dataset's illustration style. Most use the first
  frame; 1368, 0257 and 1167 use a mid-action frame because the first frame

  reduced motion enabled.

License record:

  an MIT file but its README states the author does not own the media and
  rights belong to the original creators / dataset owner. Therefore these
  warm-up/stretch media are NOT copyright-cleared for commercial use.

Release status:
  LEGACY / PROTOTYPE-ONLY, consistent with the rest of the personal prototype.
  Do not describe them as commercially safe. Replace with commissioned or
  clearly licensed demonstrations before any public commercial release.
  The exercise names, target muscles, positions, and Chinese cues shown in the
  app are original text written for this project (not copied from the dataset,
  which only provides English instructions).
