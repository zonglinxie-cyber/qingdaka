Exercise media provenance and release notes
Updated: 2026-07-24

1) Project-generated static illustrations used by this application

Files:
  generated/bird-dog-anatomy.png
  generated/farmer-carry-anatomy.png
  generated/wall-plank-anatomy.png
  bird-dog.gif
  bird-dog-poster.png

The bird-dog.gif / bird-dog-poster.png pair is a project-original looping
demonstration generated for this app (four-point kneel to contralateral
reach). It was not derived from a RepDB or Kaggle GIF, and no third-party
exercise GIF was used as an image input or style reference.

Status:
  PROJECT-ORIGINAL GENERATED ASSETS. These three 512 x 512 PNG stills were
  generated specifically for Workbuddy to match its anatomical illustration
  language. wall-plank-anatomy.png was generated from text-only project art
  direction. That newly generated project-original wall-plank image was then
  used only as the style reference for farmer-carry-anatomy.png and
  bird-dog-anatomy.png. No RepDB image or legacy GIF/poster was supplied as an
  image input, style reference, conditioning image, or training material at
  any stage of the final generation.

Usage:
  These files are the deployed static references for bird dog, light farmer
  carry / in-place hold, and wall plank. They are not complete motion
  demonstrations. Keep the written regressions, safety cues, and
  "static posture reference" labels with them.

3) Legacy GIF and poster files

Historical set:
  0276, 0291, 0292, 0404, 0659, 0710, 1373, 1459, 1677, 3013, 3239
  (.gif and -poster.png)

Deployment scope:
  0710.gif and 0710-poster.png are no longer referenced by the active routine
  and are explicitly excluded from deploy/ and the PWA cache.
  0659-plank-poster.png is deprecated and also excluded.
  The other ten legacy GIF/poster pairs remain in the current personal
  prototype and therefore retain the release restriction below.

Current host:
  https://github.com/omercotkd/exercises-gifs

The host repository contains an MIT LICENSE file, but its README explicitly
states that it is a backup of a Kaggle exercise-animation dataset, that the
repository author does not own the content, and that rights belong to the
original creators and dataset owner. Therefore the host's MIT file is not a
complete or reliable chain of title for the media.

Release status:
  LEGACY / PROTOTYPE-ONLY. Do not describe the remaining ten deployed pairs as
  copyright-cleared or commercially safe. Replace them with commissioned,
  self-recorded, or otherwise clearly licensed continuous demonstrations
  before treating the application as a public commercial release.

No legacy GIF or poster was used as an input or reference for the three
project-generated static illustrations.

  The exercise names, target muscles, positions, and Chinese cues shown in the
