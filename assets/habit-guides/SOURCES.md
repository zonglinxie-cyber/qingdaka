# 轻量活动习惯：内容依据与原创示意图

核对日期：2026-11-05。本次重新获取并阅读了下列官方网页，包括 NHS 坐姿练习页。

## 定位与边界

- 内容用于建立轻量活动与睡眠习惯，不是治疗、康复或健身处方，不承诺减重、治痛风、治疗失眠或睡眠呼吸暂停。
- 长期没有运动，或有慢性病、关节问题、容易气短、平衡困难时，开始前先与医生或相关健康专业人员讨论适合的活动与强度。坐姿不是人人安全的默认方案。
- 痛风发作或疑似发作时不开始或继续课程；休息并抬高患肢，不给患处施压，按医疗建议处理。不自动改为坐姿继续。
- 站姿仅在站立、走路无痛且稳定时使用。坐姿要求椅子无轮、无旋转、承重适合、稳定不晃，双脚能平放；不是通过扶椅硬撑来完成动作。
- 疼痛、头晕、恶心、异常气短或不稳时停止；胸痛、严重呼吸困难、晕厥等需要立即寻求急救。具体提示见 `QDK_CONTENT.safety`。
- 不含拳击、慢拳、快速转脚、跳跃、外加负重或上下地面的动作。短回合、充分休息、清晰口令只是交互编排方式。
- 本内容没有经过专业人员逐动作核定或临床验证。官方来源不代表对本课程、时长或图示的认可。

### 坐姿动作的改编说明

- **坐姿轻柔动臂**：参考 NIDDK 对坐姿活动手臂的一般描述，设计成低于肩的小幅侧开与放回。它不是 NHS 坐姿页上的同名标准动作，也不是专业核定动作。
- **坐姿小幅开胸**：参考 NHS Chest stretch 的坐稳、肩轻向后下、双臂侧开与胸口略向前上。缩小幅度，手保持低位，不顶腰；舒适时停约 5 秒再放松，不要求持续整个回合。
- **坐姿轻抬膝**：参考 NHS Hip marching 的坐直、轻扶椅侧、屈膝抬一腿、控制放回后换腿。这里只提示脚稍离地，不追高度或次数，不借手臂用力撑起身体。
- **坐姿温和转头**：参考 NHS Neck rotation 的肩放松、缓慢向一侧转头、舒适时约停 5 秒再回正和换侧。不用手扳头、不绕颈，不要求回合内完成两侧。
- NHS 原页开胸建议保持 5–10 秒、重复 5 次；抬膝每侧 5 次；转头保持 5 秒、每侧 3 次。**本项目没有照搬这些组数或次数**，也没有把它们换算成等效的 20 秒运动剂量。
- **室内慢走**：参考 NIDDK 步行与慢慢开始的原则；采用清空的短直路线，小步慢走，末端停稳，空间不够就结束，不快速转向。
- **站姿放松肩膀**：本项目的小幅姿态提示，只做肩轻向后下再回自然位；不是 NHS 坐姿练习的站姿认证版本，不含大幅绕肩或耸肩训练。

## 课程编排与时长

三个课程是主动选择的时长选项，不是体能等级。默认 `gentle`（3 分钟），可主动选择 `minute`（1 分钟）；`steady`（5 分钟）只增加同样的短回合，不自动解锁、升级或加快动作。

每个回合为 `move 20 秒 + rest 15 秒`，最后一个回合后也保留休息，然后收尾。坐姿与站姿时长完全一致，但使用各自的准备、动作、休息和收尾内容。

| 课程 ID | 准备 | 回合数 | move 合计 | rest 合计 | 收尾 | 总秒数 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| `minute` | 15 | 1 | 20 | 15 | 10 | **60** |
| `gentle` | 20 | 4 | 80 | 60 | 20 | **180** |
| `steady` | 25 | 7 | 140 | 105 | 30 | **300** |

- 坐姿按“轻柔动臂 → 小幅开胸 → 轻抬膝 → 温和转头”循环；一分课程只取第一个动作，五分课程取前七个回合。
- 站姿按“放松肩膀 → 室内慢走”循环；一分课程只做放松肩膀，没有强制步行。
- 上述秒数是本项目设计的**计划时长**，不是官方运动剂量、最低完成时间或疗效承诺。
- 准备没好就暂停，休息可延长，任何时候都能结束，不补时或补次数。实际时长因此可以与计划不同。
- `activeSeconds` 只计 `kind === 'move'`；准备、休息、收尾不计入活动。计划值不能冒充实际完成值。

## `window.QDK_CONTENT` API

`content.js` 使用 IIFE 暴露内容，不访问 DOM、个人资料、存储或网络，不调用计时器，不引用旧外部 GIF 或预录语音。

| 字段 / 方法 | 契约 |
| --- | --- |
| `courses` | 数组：`{id, name, minutes, description}`，ID 为 `minute`、`gentle`、`steady`，分钟数为 1、3、5。 |
| `modes` | 数组：`{id, name, description, equipment, caution, image}`，ID 为 `seated`、`standing`。 |
| `defaultCourseId` | `'gentle'`。 |
| `defaultMode` | `'seated'`，仅为界面初始选项，不代表已确认适合活动，也不是站姿不适时的回退方案。 |
| `buildPlan(courseId, mode)` | 接收 ID 字符串，返回新的步骤数组。省略参数使用上述默认值；显式传入未知 ID（包括 `null`）抛出 `RangeError`，不静默换课程或姿势。 |
| 计划步骤 | 必含 `{id, kind, name, seconds, cue, steps, image}`；`kind` 为 `prepare`、`move`、`rest`、`settle`，`steps` 恰好 3 条，所有步骤有图和短口令。 |
| 步骤扩展字段 | `mode`、`activeSeconds`、`imageAlt`、`caution`、`mediaNote`；活动步骤另有 `moveId` 对应动作库。每份计划的步骤 ID 唯一，`steps` 数组按次复制。 |
| `activeSeconds(plan)` | 仅累加 `move` 步骤的 `seconds`。完整计划分别返回 20、80、140；非实际完成时长。 |
| `moves` | 可用于无计时学习的数组：`{id, name, cue, steps, image, caution}`，另有 `mode` 和 `imageAlt` 便于过滤与无障碍展示，共 6 个动作。 |
| `safety` | 通用定位、开始前讨论、停止信号、急救、痛风、关节紧急评估、椅子与站姿要求、计时与图示限制。 |
| `habits` / `sleep` | 含 `title`、`description`、`tips`；`sleep.seekHelp` 提示就医评估。 |
| `sources` | 数组：`{title, url, note}`，包含上述 7 个来源。 |
| `mediaNote` | 原创分步示意、非专业视频、不表示精确角度或必须达到的幅度。 |

```js
var content = window.QDK_CONTENT;
var plan = content.buildPlan(); // gentle + seated
var total = plan.reduce(function(sum, step){ return sum + step.seconds; }, 0); // 180
var plannedActive = content.activeSeconds(plan); // 80
var shortStanding = content.buildPlan('minute', 'standing'); // 总计 60 秒
var seatedLibrary = content.moves.filter(function(move){ return move.mode === 'seated'; });
```

### UI 接入边界

- 此次只更新内容模块和本目录资源。现有 `app.js` 仍检查旧的 `QDK_CONTENT.routines`，未适配本 API；**单独替换内容不会让旧页面自动使用新课程，旧初始化检查会报错并停止**。没有保留旧课程或借用旧语音来假装兼容。
- 后续 UI 应从 `courses`、`modes` 和 `buildPlan` 读取内容，提供 1 分钟选项、主动选择模式、暂停、停止、延长休息及无计时学习入口；不把 5 分钟作为自动进阶。
- 开始前展示安全提示与模式条件，不能把 `buildPlan` 当成健康评估。它只生成内容，不读取症状或决定是否允许活动；出现发作或停止信号时应停止，而不是调用另一模式继续。
- 记录实际活动时，仅累加真正进行的 `move` 时间，排除暂停、跳过、提前结束的剩余时间和非活动阶段。
- 使用 `imageAlt` 作为外部 `<img>` 的替代文本，显示 `mediaNote`、三步说明与 `caution`。SVG 内也有可访问标题和描述；不把图中的简化身体线条解释为精确姿态标准。
- 本内容没有预录语音映射。不要用旧录音替代新动作；是否生成匹配的新语音属于后续 UI 工作。

## 原创 SVG 清单与来源

下列 SVG 均为本次新绘的简化圆形、线条、椅子与身体示意；不是从官方图片描摹、下载、转换或嵌入的文件。不含照片、医学解剖图、外部字体、脚本、动画、外链媒体或跟踪请求。官方网页仅用于事实核对，网页图像不随项目分发，也不声明对第三方素材的授权。

每张图为两格准备位／目标位或停止／休息提示，含可见“分步示意 · 非专业视频”、`role="img"`、`aria-labelledby`、`<title>`、`<desc>` 与 `viewBox`，不只依靠颜色区分步骤。图像只帮助理解动作方向，不表示关节精度或适合任何人。
