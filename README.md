# 轻打卡 · 个人科学跟练版

纯自用、零记账打卡、零免责安检弹窗、100% 恢复 3D 肌肉解剖动图。

应用浓缩为一件事：**用科学编排的「A → B → C 周循环计划」清晰教你动作、带着你练完即走。**

## 核心亮点

- **100% 3D 肌肉解剖动图**：红白发力肌群一目了然，动作规范，无火柴人 SVG。
- **三档声音模式切换**：支持精炼教练口令、极简节拍哨音与静音一键切换。
- **科学周循环 A → B → C**：
  - **A · 徒手根基**：大腿臀部复合与深层核心，椅子托底护膝，零跑跳冲击。
  - **B · 哑铃塑形**：居家一对哑铃平衡推拉肌力，对冲久坐圆肩驼背。
  - **C · 核心体态**：斜板支撑、轻负重持重与对角协调，强化躯干稳定性。
  - **随时切场景课**：久坐全身拉伸（8 节经典解剖拉伸，随时松解）、健身房固定器械全身课。
  - 每次自然练完周循环课，自动推进书签（A → B → C → A），下次打开直达推荐课。
- **4 档科学强度一键切**：
  - 恢复档（1 轮 · 25 秒/动 · 休 25 秒 · 约 8~9 分钟）
  - 入门档（默认 · 1 轮 · 40 秒/动 · 休 25 秒 · 约 11~13 分钟）
  - 标准档（2 轮 · 45 秒/动 · 休 20 秒 · 约 17~20 分钟）
  - 进阶档（3 轮 · 50 秒/动 · 休 15 秒 · 约 23~27 分钟）
- **单练体验 30 秒**：动作列表点击任意项展开 3D 解剖动图、主次肌群、三步做法与避坑红框，点击「单练体验 30 秒」立即把动作摸熟再进整课。
- **零弹窗开始，直关退出**：点「开始跟练」零弹窗直接进入播放器；中途点击「结束」直接干净关闭回主页，不弹任何问卷。
- **双视口自适应**：在 `320×560` 与 `390×844` 尺寸下主页无横向滚动，播放器一屏内状态、动图、口令与控制栏完整可见。

## 本地运行

```bash
python3 serve.py
```

浏览器打开 `http://127.0.0.1:8899/index.html`。

## 测试与构建验证

```bash
# 1. 运行可靠性单元测试（session 与 sw 离线缓存）
npm run test:reliability

# 2. 运行源码端到端测试（Playwright Chrome）
PLAYWRIGHT_CHANNEL=chrome npm run test:e2e

# 3. 构建发布包
npm run build

# 4. 校验发布包（课程结构、无孤儿媒体、hash 精确匹配）
npm run check:dist

# 5. 校验发布包产物端到端测试
PLAYWRIGHT_CHANNEL=chrome TEST_UNIT_PAGE=0 npm run test:e2e
```
